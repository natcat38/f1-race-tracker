**Goal:** Every good and bad path in the web UI shows a truthful, human-readable state — no silent hangs, no misleading "Reconnecting…" for unrecoverable failures, no dead buttons, no whole-app blanking when one panel crashes — verified by a browser walkthrough and pinned by vitest tests.

**Architecture:** The frontend is a Vite/React 19 SPA in `web/` with hash routing in `web/src/App.tsx` (routes: default board, `#compare`, `#ghost`, `#settings`). Two data sources share one interface: `connectRace` (reconnecting WebSocket, `web/src/realtime/socket.ts`) and `connectStaticReplay` (baked NDJSON, `web/src/realtime/staticReplay.ts`), both reporting a `ConnStatus`. This plan (a) walks all paths in a real browser to log defects, (b) fixes the five known error-UX gaps found in research, (c) re-verifies.

**Tech Stack:** React 19, TypeScript, Vite 8, vitest 4 (node env, NO jsdom, NO testing-library — render tests use `renderToStaticMarkup` from `react-dom/server`, already installed). Go gateway (`cmd/server`) serves `/ws`, run via `docker compose up --build -d` at `http://localhost:8080`.

Replace `web/src/ErrorBoundary.tsx` with:

```tsx
import { Component, type ReactNode } from 'react'

// ErrorBoundary keeps a render-time exception in one component from unmounting
// the whole app to a blank page. Logs the error and shows either the provided
// compact fallback (per-panel use) or the full-page reload prompt.
export class ErrorBoundary extends Component<
  { children: ReactNode; fallback?: ReactNode },
  { error: Error | null }
> {
  state: { error: Error | null } = { error: null }

  static getDerivedStateFromError(error: Error) {
    return { error }
  }

  componentDidCatch(error: Error) {
    console.error('app crashed', error)
  }

  render() {
    if (this.state.error) {
      if (this.props.fallback) return this.props.fallback
      return (
        <div style={{ padding: 24, fontFamily: 'sans-serif' }}>
          <h1>Something broke.</h1>
          <p>Reload the page. If it keeps happening, check the browser console.</p>
        </div>
      )
    }
    return this.props.children
  }
}
```
