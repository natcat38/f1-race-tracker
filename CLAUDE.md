## Agent skills

### Issue tracker

Issues live in GitHub Issues — use the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default label vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Repo memory — read before crawling the tree

- **`FILE-MAP.md`** (repo root) — layout: what every directory and source file is
  for, grouped by layer. Generated by `scripts/gen_file_map.py` and CI-gated;
  don't hand-edit it. New directory → add a `DIRS` row in that script; new file →
  give it a header comment, then regenerate.
- **`CONTEXT.md`** (repo root) — vocabulary.
- **`docs/adr/`** — decisions.
- **`docs/agents/*.md`** — how-tos. See `docs/agents/domain.md`.
